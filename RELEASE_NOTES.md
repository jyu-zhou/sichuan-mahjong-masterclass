# Sichuan Mahjong Masterclass v1.3.2

Current stable bilingual release.

## 中文

### 本版包含

- 34 堂循序课程与 45 道互动练习；
- 中文默认课程与完整 English edition；
- 番型图鉴、摆牌实验室、概率/收益计算与连续读牌工具；
- 中英文 Markdown / HTML 教材；
- `standalone.html` 双语单文件离线版；
- `AGENT_GUIDE.md` / `AGENT_GUIDE.en.md`，用于让教学 Agent 先读取当前项目再授课。

### 下载

- **中文离线包**：`Sichuan-Mahjong-Masterclass-zh-CN-v1.3.2.zip`
- **English offline bundle**：`Sichuan-Mahjong-Masterclass-en-v1.3.2.zip`
