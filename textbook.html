四川麻将大师教材 v1.3.2

定位：面向零基础学习者的四川麻将（简称“川麻”）系统教程。主线采用四人、万筒条108张、换三张、固定定缺、不吃、可碰杠、血战到底，并按当前番型表与终局结算规则教学。

目标：从“能合法打一局”进阶到“能用牌效率、概率论、期望收益和逐家风险解释自己的决策”。本教材不承诺胜率或盈利。

<a id="如何使用本书"></a>

如何使用本书

建议按章节顺序学习。每课完成三个动作：①复述规则或数学前提；②在互动网页中动手验证；③用本课验收题检查是否真正理解。新手不要直接跳到读牌和概率章节，因为高级判断建立在合法性、牌张守恒和听口枚举之上。

<a id="规则合同"></a>

规则合同

本书采用“当前规则优先”的原则：游戏内规则页与番型表是主规则集；腾讯《欢乐麻将》公开资料用于交叉核对基础机制，但若历史赛事与当前场次冲突，不进行混拼。

<a id="已锁定规则"></a>

已锁定规则

  • 基本牌局：四人、万筒条108张、换三张、固定定缺、不吃、可碰杠；采用血战到底。
  • 基本番型：平胡1倍；碰碰胡2倍；清一色/七对/金钩钓4倍；清十八罗汉256倍等，详见番型表。
  • 附加条件：自摸、杠上花、杠上炮、抢杠胡、海底捞月、每根均按×2处理；重复计数必须避免。
  • 天胡与地胡：按当前场次封顶倍数直接结算，不再与其他番型叠加。
  • 查大叫：未听者向听牌且未胡者按最大可能胡牌倍数赔付，不含自摸倍数。
  • 查花猪：仍持本人定缺花色时构成花猪；对每名应收玩家按max(64倍,该玩家最大可胡倍数)结算。
  • 退税：牌墙摸尽且未听牌时，退回本局全部杠牌所得。
  • 呼叫转移：杠上炮时转移该次杠牌所得；若同一炮多家胡，则不触发呼叫转移。

<a id="场次参数与保守处理"></a>

场次参数与保守处理

  • 具体场次的普通封顶倍数应以房间参数为准。
  • 复合基础番型中已经包含的四同张是否还能另算“根”，在缺少结算样本时按“不重复计数”处理。
  • 不同杠型的即时杠钱支付关系可能随场次而变化，必须与胡牌番值分账。
  • 过水解除、抢杠允许范围与其他细节若平台版本变化，应以当场规则页为准。

<a id="第1课-规则契约-本课程采用哪种四川麻将"></a>

第1课｜规则契约：本课程采用哪种四川麻将

阶段：入门　　建议用时：9分钟
学习目标：能够区分血战到底与血流成河，并理解“当前规则优先、不同来源不得混拼”的原则。

<a id="一句话记住主线"></a>

一句话记住主线

四人、万筒条108张、换三张、定缺、不吃、可碰可杠、胡了退出；三家胡或牌墙摸尽则结束。 这叫血战到底，不是胡后还能继续胡的血流成河。

规则优先级：①当前游戏规则界面与番型表；②已确认的课程规则；③腾讯《欢乐麻将》公开规则资料仅作交叉核对。不同来源发生冲突时，不可暗中拼接。

<a id="为什么这很重要"></a>

为什么这很重要

课程的策略目标不是“每盘都最先胡”，而是长期平均净得分较高，且损失的尾部风险受到控制。例如按当前规则，花猪最低可赔64倍，可能远大于一次普通平胡收益。必须先学合法性，再学进攻。

<a id="学习路线"></a>

学习路线

前4课学会辨认与操作；第5—9课学会定缺和牌效；第10—12课算分与选择；第13—16课学概率、读牌、风险与残局；最后完成综合对局与毕业考核。

注意：课程中的5元底分与普通封顶仅用于算术和决策演示；若场次参数不同，应替换为实际参数；本课程工具保留可调设置，并明确区别普通封顶和特殊花猪罚款。

验收题：不用看牌也能解释：为什么“先胡的一家退出”会改变自摸收款人数？

<a id="第2课-认识108张牌-万-筒-条"></a>

第2课｜认识108张牌：万、筒、条

阶段：入门　　建议用时：10分钟
学习目标：能辨认三花色、1—9以及“每张恰好4枚”的物理约束。

<a id="只有三门花色"></a>

只有三门花色

  • 万子：一万到九万，牌面通常写数字与“萬”字。
  • 筒子：一筒到九筒，牌面用圆圈表示。
  • 条子：一条到九条，牌面用竹条图案表示。

每一种牌恰好4张，3门×9个点数×4张＝108张。本模式不使用风牌、字牌或花牌。

<a id="为什么要数-同一张有几枚"></a>

为什么要数“同一张有几枚”

自己持有两张5筒，同时公开区又显示同种牌数量异常时，物理上可能超过4枚，必须核对信息是否抄错。不可能事件的概率为零，比任何读牌经验更可靠。

<a id="新手练习"></a>

新手练习

进入“牌张实验室”点击三门花色，找出5筒、2万、9条；把4张同种牌加入手牌，观察系统阻止第5张加入。

不要把“我看不见”理解成“在牌墙里”。未见牌也可能在他人暗手里。

验收题：为什么“桌面公开1张＋自己持2张”只能推出未确认1张，而不能推出墙里一定有1张？

<a id="第3课-图鉴与组合动手课-麻将牌怎么-看"></a>

第3课｜图鉴与组合动手课：麻将牌怎么“看”

阶段：入门　　建议用时：18分钟
学习目标：零基础能够从牌面识别顺子、刻子、将牌及花色。

<a id="本课先看-再触摸-最后复述"></a>

本课先看，再触摸，最后复述

万子123万：同花色连续3张，一副顺子

筒子555筒：相同的3张，一副刻子

条子77条：一对将牌

<a id="用一个动作区分-形状-与-牌的数量"></a>

用一个动作区分“形状”与“牌的数量”

看见555筒，数的是三张实体牌，不是数字5加三次；看见456条，也同样是三张实体牌，不能与456筒混为一个顺子。

动手：在“摆牌实验室”摆出123万、555筒、77条，观察每一张都受4枚上限约束。然后试图把一张牌加入第五枚，系统会拒绝。

纠错：一张“七筒”永远不是7张牌；“万、筒、条各有9个点数”，每点4枚，故总数3×9×4=108。

验收题：三副例子哪一个可以作将？为什么？

<a id="第4课-胡牌的骨架-顺子-刻子-将与七对"></a>

第4课｜胡牌的骨架：顺子、刻子、将与七对

阶段：入门　　建议用时：17分钟
学习目标：能够将完整14张拆成4组面子+1对将，或识别七对。

<a id="标准胡牌形状"></a>

标准胡牌形状

普通胡牌是3+3+3+3+2＝14张。每组3张叫面子，可由同花色的相邻三数（顺子，如234万）或同一张三枚（刻子，如555筒）组成；最后2张同一种牌是将牌（对子）。

这副示例可拆成234万、456万、234筒、789筒、88万：普通胡成立，前提是定缺条且没有条牌。

<a id="另一个合法形状-七对"></a>

另一个合法形状：七对

七对由7个对子构成，一共14张，通常不能先碰过牌。某一牌种的4枚是否拆作两对计入七对，要以房间的具体番型规则为准；基础的七对结构允许按两个对子进行牌型分解。

<a id="三个新手误区"></a>

三个新手误区

  1. 123万和123筒不能凑成同一组顺子；2. 只凑齐4组面子但没有将，不算普通胡；3. 有14张并不代表已胡，必须能完整拆分。

练习时先把牌摊成四组三张，最后留一对。不要先数番数，再倒过来寻找是否能胡。

验收题：给出一手14张，先证明能否胡，再谈它是几番。

<a id="第5课-完整胡牌分解动画式图解"></a>

第5课｜完整胡牌分解动画式图解

阶段：入门　　建议用时：18分钟
学习目标：能用四副面子＋一对将解释14张胡牌。

<a id="从平铺的14张到五个组块"></a>

从平铺的14张到五个组块

第一副：234万

第二副：456万

第三副：234筒

第四副：789筒

将牌：88万

这手牌合计3+3+3+3+2＝14张，且缺条，符合普通胡牌结构。

<a id="为什么只看张数不够"></a>

为什么只看张数不够

  • 胡牌首先必须合法定缺。含定缺花色的14张即使可以分组，也不能认定为合法胡。
  • 已经碰牌时，展示在桌上的三张仍占一个面子位；不能拿剩余暗手机械要求14张。
  • 七对无需组顺子和刻子，但一般不可先碰。四枚同种牌可供七对拆成两对，是否形成龙七对按番型表再分类。

形成胡牌时，先问“能否胡”，再问“胡哪一型”，最后问“结算是多少”。把三个问题倒过来会造成大量错误。

验收题：这副牌已碰出555筒，余下11张暗手应当找几副完整面子、几对将？

<a id="第6课-一局怎么进行-摸牌-舍牌-碰与杠"></a>

第6课｜一局怎么进行：摸牌、舍牌、碰与杠

阶段：入门　　建议用时：14分钟
学习目标：能完整描述流程，区分碰、直杠、暗杠、补杠。

<a id="基本顺序"></a>

基本顺序

庄家14张先打，其他玩家13张；正常轮到自己时摸1张，再打1张。不能吃牌，但符合规则时可碰、杠、胡。

  • 碰：自己暗手中有两张同牌，别人舍出第三张，可拿来组成明刻；碰后要打1张。
  • 直杠（点杠）：手里有三张同牌，别人打来第四张。
  • 暗杠：手里有四张同牌，宣布杠。
  • 补杠（巴杠）：先碰了三张，自己摸到第四张补上；可发生抢杠胡。

<a id="关键动作-杠后补摸"></a>

关键动作：杠后补摸

杠是用四张实体牌占一个面子位置，因此需要按规则再补摸1张，以维持正确的面子数量；漏补摸可能导致相公，当局失去正常胡牌资格。

<a id="谁继续付钱"></a>

谁继续付钱

有人胡牌退出后，不再参与之后的正常摸打。已经胡牌的那一家通常不参与后来发生的自摸付款；实际杠钱以及此前账目以房间规则为准。

碰杠的目的不是“有机会就亮出去”。它有结构收益，也有固定牌型、泄露信息和结算风险。

验收题：碰后手里剩几张暗牌？为什么不能机械用14张检查暗手？

<a id="第7课-实战流程图-从拿牌到三家胡"></a>

第7课｜实战流程图：从拿牌到三家胡

阶段：入门　　建议用时：18分钟
学习目标：明确每个动作的前置条件和牌张数量变化。

发牌与换三张→确定缺门→庄家先舍牌→摸牌—弃牌循环→碰、杠、胡的事件判断→第三家胡／牌墙耗尽

<a id="三种常见中断"></a>

三种常见中断

  1. **他家打出可碰的牌**：若选择碰，亮出刻子，随后立即打一张，不必先再摸一张。
  2. **手中有四张相同的牌**：要杠时应正确宣杠、结算杠钱并补摸；不要因为“已有四张”就忘记补摸动作。
  3. **他家打出可胡的牌**：胡牌优先于碰杠；过水限制若存在，必须先确认是否仍有胡牌资格。

<a id="常见判定树"></a>

常见判定树

我有胡牌资格？ ─ 是 → 核验缺门与牌型 → 决定是否胡（含过水）
              └ 否 → 是否可碰/杠？ → 决定副露或等待摸牌

练习：解释为什么“已经胡牌退出”不能继续拿正常自摸收入。

验收题：有人胡牌后还会继续摸打吗？三家胡后还继续吗？

<a id="第8课-换三张独立模块-开局必须执行"></a>

第8课｜换三张独立模块：开局必须执行

阶段：开局插件　　建议用时：12分钟
学习目标：理解换牌是定缺前的结构调整，但不把换牌结论当作长期固定方案。

<a id="先正确操作"></a>

先正确操作

常见的换三张做法，是从自己的13张里挑同一花色的三张与另一位玩家交换；方向和细节由本局机制确定。具体换牌顺序、是否可从刚换回的牌中再选、方向掷骰规则，按平台实际操作。

<a id="不要只扔掉最少的一门"></a>

不要只扔掉最少的一门

例如123万已经形成顺子，147条只是相互分离的3张。在其他条件相同下，交换147条通常比交换123万破坏更小；但若其中一门承载大多数成型面子，不能机械只数牌张。

<a id="换完之后重新定缺"></a>

换完之后重新定缺

换回来的3张可能大幅改变各花色的结构，因此应当基于换完后的实际手牌重新决定缺哪一门。换三张模块不改变后续摸打、胡牌和攻守的核心流程。

<a id="高手额外记录"></a>

高手额外记录

换出的3张是玩家掌握的私人历史信息；随后它们可能被对手打出、碰杠或用于胡牌，因此不能把“换给某人”长期等价为“仍在其暗手里”。

<a id="第9课-定缺-本体系最重要的刚性约束"></a>

第9课｜定缺：本体系最重要的刚性约束

阶段：牌效基础　　建议用时：16分钟
学习目标：会把定缺看作“合法性优先的三种方案比较”，并知道残局花猪后果。

<a id="定缺不是随便扔掉一种花色"></a>

定缺不是随便扔掉一种花色

定缺后这门花色不能用于合法胡牌。到最后仍持有定缺花色，会按当前规则界面作为花猪处理。普通教学先按“手中有缺门牌时优先清缺”的保守次序练习；若平台允许中途舍其他牌，属于操作规则的变体，但花猪风险不变。

<a id="三方案比较法"></a>

三方案比较法

按缺万、缺筒、缺条依次计算：①要清走多少张；②另外两门留下几组完整面子；③搭子和对子质量；④清缺期间有哪些明显危险牌。

  • 缺门牌数越少，通常越快清净，但不是唯一因素。
  • 剩余两门牌型若成型很快，可能值得清掉数量略多的一门。
  • 定缺不是保证“只能有两门”。清一色允许最后只剩一门；不能把清一色误判成违法。

<a id="高额损失"></a>

高额损失

当前规则明确：花猪对其他玩家赔付的倍数，对每一名收款玩家分别取64倍与该玩家听牌可胡的最大倍数中的较高值。普通胡牌是否封顶不能自动限制这一特别处罚。

教学中，第一关不是让他快胡，而是让他“永远知道自己定缺了什么”。

<a id="搭子的三种形态"></a>

搭子的三种形态

45万需要3万或6万，是双面搭子；46万只能靠5万，是嵌张；12万只能靠3万，是边张。假设目标牌没有被自己或桌面占用，名义完成资源依次是8张、4张、4张。

这个8对4是理论资源，不是本局实际胡牌概率。 3万和6万可能已被对手暗持，也可能被公开耗尽。

<a id="复合结构"></a>

复合结构

34567万不只是一个顺子。它可以提供不同的搭子拆分方向，因此在面子未完全成型前往往比零散的5张有价值。

<a id="面子与将的平衡"></a>

面子与将的平衡

手里已经有4副面子却没有将，和手里有很多对子却缺面子，是两种不同的问题；不能只数“连着的牌”就决定拆哪张。

新手必练动作

<a id="第12课-听牌-有效张与公开牌修正"></a>

第12课｜听牌、有效张与公开牌修正

阶段：牌效基础　　建议用时：20分钟
学习目标：能列出所有听口，并用4减去已知数量得到未确认资源。

<a id="听牌"></a>

听牌

持有13张可形成“再加某一种牌就能完整胡”的状态，叫听牌。同一手牌可能同时听几种不同牌；“宽听”常比“死听”更快，但仍受实际可获得性影响。

<a id="有效张三层区分"></a>

有效张三层区分

  1. 理论资源：每种听口4张，减去自己手里同种牌的数量。
  2. 未确认资源：再减公开弃牌、明面副露、已确认不可获得的同种牌。
  3. 实际墙内资源：还得减对手暗持的数量；它通常未知，不能假装计算已确定。

<a id="例子"></a>

例子

玩家在听5筒，自己没有5筒，桌面公开2张5筒：最多还有2张未确认位置，不能说“摸中的概率就是50%”。

<a id="动态训练"></a>

动态训练

到牌张实验室先放13张，再点击“列听口”；还可以标记已见张数，比较公开牌变化后的听口资源。该工具仅适用于没有碰杠的完整暗手，不能直接分析副露牌。

第13课｜复合搭子的真正价值：一张牌能改变几种路线

阶段：牌效基础　　建议用时：18分钟
学习目标：从单张有效张提升到下一巡改良的分析。

<a id="先分清三种二张搭子"></a>

先分清三种二张搭子

两面搭补3筒或6筒成面子

嵌张搭只有5筒直接成面子

边张搭只有3筒直接成面子

<a id="不是每张牌的价值都能加总"></a>

不是每张牌的价值都能加总

以筒23456为例，它可能拆成234＋56，也可能23＋456。相邻搭子共享实体牌，不可以一边按234用掉4筒，一边又把同一4筒计算成另一个面子。

有效张是下一摸让手牌离听牌更近的牌；改良张是不立即降向听，但让下一步更宽的牌。评价长期路径要比较多巡，而不是只把每个搭子的理论4或8张相加。

<a id="练习"></a>

练习

请说明你有45筒时6筒为何能成456，而46筒需要5筒；为什么“8张”和“4张”仍然不是直接可自摸概率。

第14课｜向听、改良和“摸后出什么”

阶段：牌效基础　　建议用时：20分钟
学习目标：能用枚举和结构推理比较合法弃牌，不把上一步好看当成好牌。

<a id="什么是向听"></a>

什么是向听

约定：已经听牌叫0向听；离听牌还要一个有效推进称1向听。向听数衡量距离合法胡牌所需的结构改善步数，不等于“还需要摸几次”。

<a id="为什么要比较所有弃牌"></a>

为什么要比较所有弃牌

摸牌后有14张，常见误区是只考虑自己最想扔的一张。正确做法是：逐一尝试每种合法弃牌，得到新的13张，再分别评估是否听牌、听几门、理论未见几张、风险多高。

<a id="不可只靠当巡听口资源"></a>

不可只靠当巡听口资源

A方案本巡能听8张，但进张后形状不好；B方案暂时只有6张有效进张，但未来可能改善成宽听。只有在相同目标阶段、风险与收益条件下，才能用单巡进张数量决定优劣。

<a id="工具边界"></a>

工具边界

页面中的牌张实验室实现13张的听口枚举、14张弃后听口比较。它不声称能为任意非听牌手牌精确计算向听数，更不是全局最优出牌器。

第15课｜向听数专项：如何保证没有漏掉更好的出牌

阶段：牌效基础　　建议用时：18分钟
学习目标：掌握按行动枚举，而非凭直觉弃牌。

<a id="统一定义"></a>

统一定义

这本书约定：已听为0向听，还差一巡形成听牌通常称1向听。这里“差一巡”指最少有效进步的结构步骤，不是保证1巡内一定摸到。

<a id="每次摸后14张的五步枚举法"></a>

每次摸后14张的五步枚举法

  1. 罗列所有不同的可弃牌种（最多14种，不是必须枚举重复实体）。
  2. 每弃一张后得到13张手牌。
  3. 检查当前缺门是否清净，不清净则不能直接当合法听牌。
  4. 枚举27种牌作为候选补牌，检查每种是否能形成14张合法胡。
  5. 汇总听口和扣除自己手中的实体数；如有公开已见牌，再修正未确认张上界。

<a id="对照题"></a>

对照题

定缺条。将这副14张完整暗手填进“摆牌实验室”，对比弃5筒与弃7筒的不同听口，再标记部分公开牌观察排序是否变化。

这类枚举可以精确完成结构判断，却不能证明某一舍牌是长期收益最优。

<a id="一次杠牌至少有五项影响"></a>

一次杠牌至少有五项影响

  1. 直接杠钱：根据暗杠、直杠、补杠类型即时收款。
  2. 根／加番：后续胡牌若符合规则可能增加番值。
  3. 补牌机会：必须补摸，有可能提高牌效或摸到胡张。
  4. 公开信息与点炮风险：自己的牌型被锁定；杠后打炮还可能触发特殊情况。
  5. 尾局退税：当前规则已确认未听牌者退回全部杠牌所得。

<a id="呼叫转移的关键例外"></a>

呼叫转移的关键例外

当前规则明确：杠上炮，需要把杠牌所赢分数转给胡牌玩家；若这次杠上炮一炮多响，则不触发呼叫转移。 不能把公开网络上所有杠上炮的处理方式混为一谈。

<a id="先问再杠"></a>

先问再杠

是否有补杠被抢胡的可能？杠后是否仍能维持足够进张？这笔杠分在终局会不会因未听而退？

早期教学中曾使用的暗杠、直杠与补杠金额示例，是另一组桌上示例。腾讯公开赛事常见的直杠“点杠者支付2倍”等处理不同。本版统一设置为“尚需在游戏当前场次核对”，不把二者相加。

新规则补丁：杠上炮呼叫转移，一炮多响不触发。根×2可能与龙七对、十八罗汉内含四同张有重复计数问题，计算器不自动双算。

第21课｜为什么快胡与追番的答案会翻转

学习目标：能用期望收益对比两种打法，认识机会成本。

<a id="不能用-胡得更大-代替决策"></a>

不能用“胡得更大”代替决策

设快胡策略胡牌概率60%、成功收益20分；追番策略胡牌概率30%、成功收益50分，不考虑其他结局，则成功收益项分别为12和15。追番看起来略高，但只要其额外点炮、查叫或留场损失超过3分，就可能反过来落后。

<a id="期望收益"></a>

期望收益

策略价值＝所有可能最终结局的净分×对应概率，再求和。 切记不能只比较一次成功时赢多少，也不能拿网上不适用本桌的胡牌概率代入。

<a id="已封顶时"></a>

已封顶时

假如自摸单家已经到达普通封顶，再多做一根不会提高这一项收入。此时牺牲进张、增加点炮风险，可能使追番成为劣策。

<a id="真正可执行的问法"></a>

真正可执行的问法

“为了多赚多少，我要增加几次摸牌？会多暴露什么牌？同局其他活跃玩家有多少？如果流局我可能赔多少？”

高手不应该一味快，也不应该一味大，而是知道何时应改变路线。

<a id="第22课-概率论第一课-墙内概率与超几何分布"></a>

第22课｜概率论第一课：墙内概率与超几何分布

阶段：概率与推断　　建议用时：18分钟
学习目标：能使用不放回抽样公式，并陈述何时不可以使用。

<a id="最易记的数学结构"></a>

最易记的数学结构

如果已经知道墙里有W张牌，其中K张目标牌，而且自己将从这堆墙不放回随机抽取n张，则至少抽到一张目标牌的概率是：

P＝1－C(W－K,n)／C(W,n)。

例：墙里20张，确定有3张目标牌，连续摸2次，则没摸到的概率为17/20×16/19＝0.7158，至少摸到一次约28.42%。

<a id="为什么不能直接代入-未见张"></a>

为什么不能直接代入“未见张”

假设已知目标牌还有3张未见，但不知道这3张是墙中还是对手暗手中。此时不能说W=20、K=3，因为K未确定。真正的墙内数量可能是0、1、2、3，需要分布推断。

<a id="把公式变成操作"></a>

把公式变成操作

进入“概率实验室”调整W、K、n，观察概率怎样变化；再把K解释成“确知墙内”，而不是“我看不到的张数”。

<a id="算得越准越危险的场景"></a>

算得越准越危险的场景

牌墙是否随机、前面是否有人胡了提前退出、自己是否真能连续摸n次，都可能改变事件和概率模型。

验收题：未见三张但不知它们在哪里时，为什么不能把K直接设为3？

<a id="第23课-从实体张数到概率-超几何分布一步步推"></a>

第23课｜从实体张数到概率：超几何分布一步步推

阶段：概率与推断　　建议用时：18分钟
学习目标：理解概率的样本空间、事件与无放回抽样。

<a id="三层资源-不能混为一谈"></a>

三层资源，不能混为一谈

未见牌数量＝4−自己持有−公开已见。它是分散在对手暗手和牌墙的“未确认位置”上界。 牌墙中目标张数需要更多隐藏信息；在没有额外信息时，若采用均匀随机分配近似，应列出“条件假设”。 未来我会摸到的张数受其他玩家摸、碰、杠、退出影响，不能直接把墙深当成我能摸的次数。

<a id="严谨抽样公式"></a>

严谨抽样公式

墙里已知W张、其中目标K张；连续随机无放回抽取n张，至少命中一次：

P＝1−C(W−K,n)／C(W,n)

举例，墙里确知20张、目标3张，抽2张：1−(17/20)×(16/19)≈28.42%。

<a id="为什么不是3-20-2"></a>

为什么不是3/20×2？

那会把两次抽样当成独立、还忽略第一张抽中后已实现事件；即使数值近似接近，逻辑也不正确。

动手：切到“计算”更改W、K、n，观察概率如何变化。设置K=0验证概率恒为0。

验收题：不知道墙中K时能不能直接用这个公式？

<a id="第24课-概率论第二课-条件推断与动态读牌"></a>

第24课｜概率论第二课：条件推断与动态读牌

阶段：概率与推断　　建议用时：18分钟
学习目标：能区分确证、排除和带条件的行为推断。

<a id="信息分成三类"></a>

信息分成三类

确定信息：公开弃牌、明面碰杠、自己的牌、已知换出牌、已胡退出的身份；规则约束：对手定缺什么、能否合法胡某花色；概率线索：对手突然改变舍牌、连续碰某门等行为。

<a id="条件概率怎么更新"></a>

条件概率怎么更新

设对手已经听牌的先验概率为20%。若某一动作在听牌状态下出现概率为60%，在未听状态下为30%，则看到动作后听牌概率为：

0.2×0.6／(0.2×0.6＋0.8×0.3)＝1/3。

这些数字只是示范“怎样算”，不是麻将真实统计值。

<a id="时间维度"></a>

时间维度

经过一次摸牌后，对手可能从未听变成听、从听改成更宽的听口。跨巡证据不能一律当作同一固定状态的独立观测反复相乘。

<a id="课堂练习"></a>

课堂练习

对手定缺条，已经清缺；此时打出5万：可以确定其对5条不合法胡，但不能确定5万安全。只要其他两名对手仍在，安全性就必须逐家判断。

<a id="第25课-隐藏信息与贝叶斯-读牌不是读心"></a>

第25课｜隐藏信息与贝叶斯：读牌不是读心

阶段：概率与推断　　建议用时：18分钟
学习目标：会给假设、先验、似然和后验设清楚边界。

<a id="构造可检验的假设"></a>

构造可检验的假设

H表示“甲当前已听牌”，E表示“甲在这一巡碰出一组条并弃筒”。假设此前估计P(H)=20%；若在听牌状态看到E的概率60%，未听时看到E的概率30%，则

P(H|E)=0.2×0.6/[0.2×0.6+0.8×0.3]=1/3。

数值是演示，不是欢乐麻将实测数据。没有玩家行为样本，就不能宣称某次碰牌一定使听牌概率提高10%。

<a id="时间轴上的真实困难"></a>

时间轴上的真实困难

前后两巡之间对手摸打可能改变H本身。如果用上一巡的听牌概率直接乘新一次的独立似然，就漏掉了状态变化。

更严谨做法：先用“可能已进张、倒退、仍听”的转移模型得到新先验，再观察新弃牌更新后验。牌谱没有完整信息时，采用“提高/降低/证据不足”三级判断往往比报虚假的百分比更好。

<a id="看对手时最该牢记"></a>

看对手时最该牢记

定缺造成的强制出牌信息弱；清缺后主动拆搭可能提供更强信息；但也可能为防守或番值转换，不能凭一次动作断言必听。

<a id="第26课-逐家防守与风险临界线"></a>

第26课｜逐家防守与风险临界线

阶段：概率与推断　　建议用时：19分钟
学习目标：能用概率×损失度量风险，并避免在多家同时点炮时漏算。

<a id="每次舍牌-先问三家分别可能怎么反应"></a>

每次舍牌，先问三家分别可能怎么反应

对手A定缺万，打万不会让A合法点炮胡；但B和C可能听万，不能因此把万子叫全桌安全张。

<a id="最简单的攻守阈值"></a>

最简单的攻守阈值

假设进攻方案能比安全方案多赚4分，但多了1次80分的点炮风险，那么使收益打平的额外概率是4/80＝5%。如果风险增加超过5%，这个简化模型下进攻不值。

<a id="何时这个阈值失效"></a>

何时这个阈值失效

若同时可能一炮多响，要计算对每个胡牌者的实际赔付及同时事件；若行动也改变听牌概率、查叫和杠收，不能只比较上面的两个数字。

<a id="不知道点炮概率怎么办"></a>

不知道点炮概率怎么办

用保守区间：假设风险在1%—10%之间，预计损失在40—80分之间，计算最坏情况，并写明自己的决策何时会翻转。避免捏造“这张牌点炮概率正好7.23%”。

<a id="第27课-逐家风险总账-谁能胡-胡多大-谁付款"></a>

第27课｜逐家风险总账：谁能胡、胡多大、谁付款

阶段：概率与推断　　建议用时：18分钟
学习目标：训练把“安全牌”改为逐家风险向量。

<a id="玩家打出一张牌t-真正面对三份不同风险"></a>

玩家打出一张牌t，真正面对三份不同风险

损失期望(t)=Σ[对家j胡此张的概率×该家的实际点炮款]＋其他直接损失。

求和不能误用相互独立的前提：若一炮多响，各家可以同时胡，损失金额的线性期望仍允许把各家期望相加；但“至少一人胡”的概率不能直接相加。

<a id="一个只用于理解的假设"></a>

一个只用于理解的假设

乙胡这张的概率10%、胡牌赔8分；丙胡牌概率5%、赔64分，则两项点炮损失期望为0.1×8+0.05×64＝4分。即使另一张牌的点炮概率略低，只要可能点高番，损失可能更大。

<a id="定缺严格是-逐人条件"></a>

定缺严格是“逐人条件”

甲定缺万，打万对甲的合法胡牌风险为0，但乙、丙仍可能胡万；一张牌对甲安全，不代表全桌安全。

条件概率应由真实可观察信息更新，不能把课堂演示的10%当作实战估值。

<a id="第28课-流局四大结算-查花猪-查叫-退税-呼叫转移"></a>

第28课｜流局四大结算：查花猪、查叫、退税、呼叫转移

阶段：高级实战　　建议用时：21分钟
学习目标：准确复述规则界面规则，并分清哪些机制仅在特定事件触发。

<a id="终局优先级"></a>

终局优先级

到牌墙摸尽时，通常先确认谁仍持有定缺花色，再判别听牌及退税；已正常胡牌退出者不应被算作“未听牌的输家”。

<a id="查花猪-特别罚款"></a>

查花猪：特别罚款

当前规则规定：仍持有定缺花色的是花猪，向其他玩家支付的倍数是对每名应收玩家分别取max(64，该玩家听牌可能最大倍数)。它不应被普通胡牌封顶不加说明地压到16倍。以仅用于教学的基础分5计，64倍就是每位应收者至少320分。

<a id="查大叫"></a>

查大叫

未听牌者赔给听牌且尚未胡牌的玩家按可能最大胡牌倍数计算的金额，不包括自摸加番。与已经听牌者不同，没听的通常既不能拿查叫钱，也可能要赔钱。

<a id="退税"></a>

退税

未听牌者把之前全部杠牌所得退回。规则界面没细化接收名单及“一炮多响以外呼叫转移转走的杠款”如何避免重复结算；真实操作以平台判定。

<a id="呼叫转移并不等于流局罚款"></a>

呼叫转移并不等于流局罚款

它发生于杠上炮，将杠牌所得转给胡牌者；规则界面注明一炮多响时不触发。应单独记事件账，不能在查大叫时混算。

行为优先级：合法清缺与避免花猪 → 争取合法听牌 → 再优化胡牌番值和高风险舍牌。这是默认检查顺序，不是要求任何情况下都无条件牺牲全部牌效率。

终局新规：查大叫按最大可能番种、不含自摸；花猪至少64倍且逐家比较；退税为未听者退还全部杠收入；呼叫转移与一炮多响的例外要分账。

验收题：分别列出“查大叫和花猪赔给谁”“自摸番是否计入查大叫”“一炮多响是否呼叫转移”。

第29课｜残局结算实战：查叫、查花猪、退税、呼叫转移

阶段：高级实战　　建议用时：18分钟

<a id="终局规则拆解"></a>

终局规则拆解

  1. 退税：未听玩家退还全部杠牌所得；退款去向可能依据杠钱原路径，规则界面没有完全给出具体归还账户结构。
  2. 查大叫：未听者赔给听牌、且尚未胡牌的对手，以该对手能胡的最高倍数、不包含自摸倍数计算。
  3. 查花猪：当前手里还有定缺花色的玩家，对非花猪玩家按max(64倍,该玩家听牌可胡最大倍数)支付。各玩家最大叫不同，不能用全桌一个值套所有人。
  4. 呼叫转移不是只在流局发生，而是杠上炮事件发生时结算；这里只作账目统一复核。

<a id="算例-不要把普通封顶用于特殊罚款"></a>

算例：不要把普通封顶用于特殊罚款

假设底分为5元，花猪赔给甲的依据为max(64,16)＝64倍、给乙的依据为max(64,128)＝128倍，则花猪对甲320元，对乙640元。这只是根据给定倍数的乘法例子，是否须额外查叫、如何分配退税，不能擅自推定。

反例：说“普通平胡封顶16倍，所以花猪最高也只16倍”与规则界面不符。

验收题：底分5时max(64,128)罚款是多少？

第30课｜完整局势推演：从开局到最后一张

阶段：高级实战　　建议用时：21分钟
学习目标：能在时间轴上反复修订同一手牌的策略。

<a id="第0巡-换牌和定缺"></a>

第0巡：换牌和定缺

初手万567、筒234、条789，加其他牌的结构尚不稳定。换牌后重新做三方案定缺卡，不要把第0巡想法锁死。

<a id="第3巡-清缺尚未完成"></a>

第3巡：清缺尚未完成

即使摸到极适合保留的其他花色牌，仍应警惕持有缺门牌导致终局花猪。清缺次序还可考虑同门几张牌在早中晚打出去的危险差异。

<a id="第6巡-对手第一次碰筒"></a>

第6巡：对手第一次碰筒

先记“某对手有2张同种筒，公开了一副筒刻”。这提升某些牌型可能性，却不保证他听牌，更不保证他做清一色。

<a id="第9巡-已有一家胡"></a>

第9巡：已有一家胡

从4位活跃者变为3位，自摸收款人数减少。之前值得等待的高番路线现在可能更难回本。

<a id="第12巡-对手再碰一组筒"></a>

第12巡：对手再碰一组筒

根据其定缺、公开弃牌和其他可见信息更新判断。不要把“连续两碰”当成独立且时间不变的固定状态证据。

<a id="尾局-墙浅-查叫逼近"></a>

尾局：墙浅、查叫逼近

这时能否合法听牌、是否需要退税、有没有花猪，比“手上原来可以做多大”更紧急。最终选择仍须比较舍牌点炮风险。

<a id="反事实问法"></a>

反事实问法

“如果当时弃另一张，能否更快听牌？我当时是否知道某张已经死光？如果后来输了，我的原决策真是错的吗？”评价决策不得使用当时不可见的牌墙顺序作弊。

<a id="第31课-完整局势推演-两人已胡后如何重新优化"></a>

第31课｜完整局势推演：两人已胡后如何重新优化

阶段：高级实战　　建议用时：18分钟
学习目标：掌握随着剩余对手人数变化而变化的牌值。

<a id="同一听牌在不同阶段产生不同的收入"></a>

同一听牌在不同阶段产生不同的收入

若单人自摸收款为每人16底分，四家都未胡时理论可从三名对手收取总计48底分；已有一人胡后只剩两名付款者，合计32底分；已有两人胡后只剩一名付款者，合计16底分。

条件：只比较正常自摸、所有未胡对手都依法支付、无特别包赔和其他附加项。它不是预测某次自摸的成功概率。

<a id="决策翻转"></a>

决策翻转

早期为了大牌牺牲1巡，有机会从多名对手收高额番款；晚期对手数量减少、牌墙缩短、未听被查大叫，追番的边际回报可能被快速听牌或退出保护击败。

<a id="行动清单"></a>

行动清单

(1) 当前未胡人数；(2) 我是否清缺；(3) 我是否合法听牌；(4) 最高番有无封顶；(5) 对手副露与已现牌；(6) 还能摸几次（不是总墙深）。

练习：同一个16倍自摸听口，从三家付到一家付，收入比例如何变？

验收题：为什么只剩两人对局时大牌的期望收益需要重新计算？

一个简单的统计警告

<a id="附录a-数学工具箱"></a>

附录A｜数学工具箱

<a id="a-1-牌张守恒"></a>

A.1 牌张守恒

任何具体牌只有4枚。若某牌自己持有h枚、公开可见v枚，则它的未确认位置上界为4-h-v。这里的“未确认”包括对手暗手与牌墙，不能直接解释为墙内张数。

<a id="a-2-不放回抽样"></a>

A.2 不放回抽样

若墙内确知有W张牌，其中K张是目标牌，并且未来自己确实会从该墙随机无放回摸n张，则至少命中一张目标牌：

P=1-C(W-K,n)/C(W,n)

只有K确知时才能直接使用。把“未见张”当作K属于样本空间错误。

<a id="a-3-贝叶斯更新"></a>

A.3 贝叶斯更新

若假设H表示“对手当前已听”，证据为E，则：

P(H|E)=P(E|H)P(H)/[P(E|H)P(H)+P(E|¬H)P(¬H)]

跨巡使用时必须先考虑隐藏状态已经因摸打发生变化，不能把每个动作都当成同一固定状态下的独立证据。

<a id="a-4-风险临界线"></a>

A.4 风险临界线

若进攻方案相对保守方案增加期望收益G，同时引入一次损失L的额外事件，其概率为p，最简模型下进攻的增量价值为G-pL，盈亏平衡点为p*=G/L。完整牌局还应加入多家点炮、查叫、退税、杠账和胡牌概率变化。

<a id="附录d-术语表"></a>

附录D｜术语表

  • 换三张：开局从同一花色选3张交换。
  • 定缺：声明一门必须清除的花色。
  • 向听：距离听牌的结构步骤；本书定义听牌为0向听。
  • 有效张：能够让当前结构向目标推进的牌。
  • 改良张：未必立即降低向听，但能改善后续结构的牌。
  • 花猪：终局仍持定缺花色时触发的高额特殊处罚。
  • 查大叫：流局后未听者向听牌未胡者按最大可胡倍数赔付，不含自摸倍数。
  • 退税：未听者退回本局全部杠牌所得。
  • 呼叫转移：杠上炮时将该次杠收益转给胡牌者；一炮多响时不触发。
